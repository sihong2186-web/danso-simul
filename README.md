# 🎋 초등 3학년 단소 시뮬레이터 (Danso Simulator)

초등학교 3학년 학생들의 국악 단소 학습을 돕기 위해 제작된 웹 기반 단소 시뮬레이터입니다.  
**화면 터치 운지법**과 **마이크 입김 감지(하이브리드 모드)**를 통해 소리 내기가 어려운 단소를 쉽고 재미있게 배울 수 있습니다.

---

## ✨ 핵심 기능

1. **지공 배치 및 맞춤형 제1공(뒷구멍) 위치 조절 & Lock**
   - **제1공 (뒷구멍 - 왼손 엄지)**: 화면 좌상단에 전용 플로팅 패드로 배치되어 있습니다.
   - **위치 조절**: 학생의 손 크기나 태블릿 파지 방식에 맞게 원하는 위치로 드래그하여 자유롭게 이동할 수 있습니다.
   - **🔒 위치 잠금 (Lock)**: 위치를 잡은 후 잠금 버튼을 누르면 연주 중 실수로 움직이지 않도록 안전하게 고정되며, 브라우저에 저장되어 재접속 시에도 유지됩니다.
   - **단소 몸통 지공**: 대나무 관 위에 제2공(왼손 검지), 제3공(왼손 중지), 제4공(오른손 중지), 제5공(항상 열림)이 직관적인 손가락 안내선과 함께 배치되어 있습니다.

2. **🌬️ 하이브리드 모드 (A안: 책상 거치 + 마이크 입김 연주)**
   - 태블릿을 책상에 올려두고, 마이크에 "후~" 입김을 불면서 화면 지공을 터치하면 실제 단소 소리가 재생됩니다.
   - **실시간 호흡 게이지**: 입김의 세기가 0% ~ 100% 게이지 및 취구 바람 이펙트로 시각화됩니다.
   - **평취 vs 역취 감지**: 부드럽게 불면 맑은 저음(평취), 세게 불면 높은 음(역취)이 자동으로 구분됩니다.
   - **👆 터치 전용 모드 지원**: 교실 소음이 심하거나 마이크가 없을 때 화면 터치만으로도 자유롭게 연주 가능합니다.

3. **🔘 100% 버튼식 터치 인터페이스**
   - 별도 키보드 없이 모든 지공을 화면 터치/클릭 버튼으로 조작합니다.
   - **멀티터치(Multi-Touch)** 완벽 지원 (여러 손가락으로 동시에 구멍을 막는 실제 연주 지원).
   - **조작 방식 선택**:
     - `🖐️ 누르고 있기 (Hold)`: 실제 단소처럼 손가락을 떼면 구멍이 열리는 모드.
     - `🔘 원터치 고정 (Toggle)`: 손이 작은 초3 학생들을 위해 터치할 때마다 열림/닫힘이 고정되는 모드.

4. **🎼 단소 5음계 음향 엔진 & 초등 3학년 연습곡**
   - Web Audio API 기반의 대나무 관악기 배음(Harmonics), 취구 마찰 바람소리(Chiff Noise), 전통 요성(Vibrato), 한옥 대청마루 울림(Reverb) 합성.
   - **실시간 율명 표시**: 仲(중), 林(임), 無(무), 潢(황), 汰(태), 夾(협).
   - **초등 연습곡 정간보 뷰어**: '떴다 떴다 비행기', '아리랑', '새야 새야 파랑새야' 수록.
   - **운지법 한눈에 보기 모달**: 초등 3학년 눈높이의 친절한 운지표 제공.

## 🚀 실행 방법

### 방법 1: `start.bat` 더블 클릭 (추천)
- 프로젝트 폴더의 `start.bat`을 더블 클릭하면 Windows 내장 PowerShell 로컬 웹 서버가 구동되고 기본 브라우저(`http://localhost:8080`)가 자동으로 열립니다.
- Node.js나 Python 등 별도 프로그램 설치 없이 즉시 실행됩니다.

### 방법 2: 브라우저에서 직접 열기
- `index.html` 파일을 더블 클릭하여 웹 브라우저에서 실행할 수도 있습니다 (터치 모드 및 기본 기능 작동).
- *참고: 마이크 입김 감지(하이브리드 모드)는 브라우저 보안 정책상 `start.bat`(localhost) 실행 시 정상 작동합니다.*
